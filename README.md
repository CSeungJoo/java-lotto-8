# java-lotto-precourse

## 기능 목록
- ## 입력 처리
    - 사용자에게 로또 구입 금액 입력받기
    - 구입 금액 유효성 검사 (1,000원 단위, 양수)
    - 사용자에게 당첨 번호 입력받기 (쉼표로 구분)
    - 당첨 번호 유효성 검사 (1~45, 중복 없음, 총 6개)
    - 사용자에게 보너스 번호 입력받기
    - 보너스 번호 유효성 검사 (당첨 번호와 중복 없음, 1~45 사이)
- ## 로또 발행
  - 구입 금액에 해당하는 로또 장수 계산
  - 각 로또마다 중복되지 않는 6개의 숫자를 랜덤 생성
  - 로또 번호는 오름차순 정렬하여 저장
- ## 당첨 확인
  - 구매한 모든 로또를 당첨 번호와 비교
  - 일치 개수 및 보너스 번호 일치 여부 판단
  - 당첨 등수 계산 (1~5등, 미당첨)
  - 당첨 결과 집계
- ## 출력
  - 발행한 로또 수량 및 번호 출력
  - 차수별 로또 번호 출력
  - 당첨 내역 통계 출력
    - 3개 일치 (5,000원) - X개
    - 4개 일치 (50,000원) - X개
    - 5개 일치 (1,500,000원) - X개
    - 5개 일치 + 보너스 (30,000,000원) - X개
    - 6개 일치 (2,000,000,000원) - X개
  - 총 수익률 계산 및 출력 (소수점 둘째 자리 반올림)
- ## 예외 처리
  - 잘못된 입력 시 IllegalArgumentException 발생
  - 에러 메시지는 "[ERROR]"로 시작
  - 구입 금액, 로또 번호, 보너스 번호 모두 예외 처리
  - 중복된 번호 입력 방지
  - 1~45 범위 벗어난 번호 예외 처리
